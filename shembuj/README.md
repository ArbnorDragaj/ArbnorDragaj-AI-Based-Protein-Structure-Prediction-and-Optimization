# Shembuj për provë

`sekuenca.csv` dhe `sekuenca.fasta` përmbajnë të njëjtat tri sekuenca **sintetike**, të zgjedhura për demonstrim. Nuk janë dataset i shkarkuar nga Kaggle ose struktura biologjike eksperimentale.

Hapi nga **Importo CSV / FASTA**, zgjidh një sekuencë dhe shtyp **Ekzekuto dhe krahaso**. Katrori me katër A mund të ketë një kontakt H–H shtesë dhe energji −1 kur pesha është 1.

Për seri nga terminali:

```powershell
.\.venv\Scripts\python.exe dataset.py shembuj/sekuenca.fasta --burimi "Shembuj sintetike te projektit" --dalja prova_demo --numri 3 --seeds 1 2 3
```

Komandën ekzekutoje nga dosja kryesore. `prova_demo` duhet të jetë dosje e re.
